# Grover-search experiment

One Grover iteration finds the marked state `11` among four possibilities. The
oracle changes its phase and the diffusion operator amplifies its amplitude.

Implementations: [NumPy](numpy/grover_search.py), [Qiskit](qiskit/grover_search.py),
[Q#](qsharp/GroverSearch.qs), [OpenQASM 3](openqasm/grover_search.qasm), and
[PennyLane](pennylane/grover_search.py).

Read the [derivation](../../docs/10-quantum-algorithms/grover-search.md).
