# Programming examples

These tutorials explain one SDK feature at a time. They complement the
[NumPy demos](../demos/README.md) and the
[cross-ecosystem experiments](../experiments/README.md).

The [Qiskit sequence](qiskit/README.md) progresses from a first circuit to
sampling, entanglement, and oracle algorithms. Run scripts from the repository
root using the installed package environment. No cloud account is required.

Examples live outside `src/` because they are learning material rather than
part of the installable `quantum_ed` API.
