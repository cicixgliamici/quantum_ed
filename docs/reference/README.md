# Reference

These pages collect conventions and compact lookup material used across the
learning path and experiments.

For a short evaluation route through the evidence, use the
[reviewer guide](../reviewer-guide.md).

- [Bit ordering](bit-ordering.md) explains how qubit indexes become displayed
  classical strings in different ecosystems.
- [Input contracts](input-contracts.md) documents supported dimensions, physical
  state checks, and the explicit normalization policy of the Python toolkit.
- [Experiment validation](experiment-validation.md) explains analytical references,
  phase-sensitive comparisons, and finite-shot statistical tolerances.
- [Scientific scope](scientific-scope.md) distinguishes identities, model assumptions,
  experimental evidence, and conditional hardware estimates.
- [Reproducible environments](reproducibility.md) explains the lockfile, Python
  matrix, installed-package checks, profiles, and environment reports.
- [Useful matrices](../09-useful-matrices/README.md) collects the matrices used
  throughout the repository.
- [Website publishing](website-publishing.md) explains GitHub Pages setup,
  local previews, and deployment troubleshooting.
