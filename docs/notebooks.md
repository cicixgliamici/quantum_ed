# Executed notebooks

Read the lessons with code, numerical results, and figures directly in your
browser. Every website build executes fresh copies of the seven source
notebooks against the installed package. An execution error stops publication.

The sequence covers setup, Bloch vectors, Bell correlations, noise and
fidelity, CHSH, teleportation, and Grover search. Each lesson is also listed
in the sidebar and available through site search.

To change parameters and run a lesson yourself, use its source download link
and the [reproducible environment guide](reference/reproducibility.md).
The published pages are static records of a successful execution.
